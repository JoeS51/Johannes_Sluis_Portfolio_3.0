# joesluis.com

Joe Sluis's personal site: a black-and-white Next.js site with some Japanese, a light/dark switch, and articles about databases and systems.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

- `app/` pages: home, `/about`, `/blog`, `/blog/[slug]`, plus link-preview images, sitemap and robots.
- `content/writing/` articles, one TypeScript module per post.
- `public/images/` images and video used by the articles.
